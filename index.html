Why register

      
An identity other apps can check without asking you

      

        
Owned by your wallet
The agent is an NFT. Only the owner can edit the profile or transfer it.

        
Verifiable by anyone
Lenders, marketplaces and other agents read the same registry by agent ID.

        
One standard
ERC-8004 uses the same registry address on every supported chain.

        
Endpoints in one place
Publish where to reach the agent: web, MCP, A2A, email, ENS or X.

        
Ready for x402

No platform fee
No account, no subscription. You pay network gas and nothing else.

      

    

  


  

    

      
How it works

      
Three steps, one transaction

      

        
01
Describe the agent
Name, description, avatar and the endpoints other apps can reach: web, MCP, A2A.

        
02
Connect a wallet
MetaMask or Rabby. The wallet that signs becomes the agent's owner.

        
03
Mint the identity
The profile is written to the official ERC-8004 registry. Gas is paid in ETH on Robinhood Chain.
